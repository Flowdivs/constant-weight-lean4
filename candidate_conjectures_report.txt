PART 2: FAMOUS / ERDŐS CONJECTURES EVALUATION

1. THE ERDŐS-GYÁRFÁS CONJECTURE (Erdős Problem #64)
   - Status: OPEN ($1,000 Cash Bounty on erdosproblems.com #64).
   - Statement: Does every graph with minimum degree >= 3 contain a simple cycle
     of length 2^k for some k >= 2 (i.e. length 4, 8, 16, 32, ...)?
   - Expected Resolution: Erdős and Gyárfás conjectured NO (counterexample exists).
   - Frontier: Checked for all graphs up to 31 vertices (Gordon Royle, Klas Markström).
     Minimal counterexample, if it exists, is 3-regular and has order N in [32, 40].
   - Lean Verification: SimpleGraph (Fin 34), verified via `decide` in < 1 second.
   - Rubric Score: 7 / 7.
   - Practical Assessment: Hardest of the viable candidates, but sparse structure
     (34 vertices, only 51 edges) makes it within reach of distributed SAT/CEGAR.

2. RAMSEY NUMBER R(5, 5) FRONTIER (R(5, 5) >= 44)
   - Status: OPEN (Narrowed to [43, 46] by Angeltveit & McKay, late 2024).
   - Statement: Find a 2-coloring of K_43 avoiding monochromatic K_5.
   - Rubric Score: 7 / 7 (on pure rubric), but Practical Difficulty: 10 / 10.
   - Practical Assessment: Extreme computational barrier. 35+ years of supercomputer
     exhaustive searches have failed. Unconstrained search space is 2^903. High risk.

3. ERDŐS-SELFRIDGE ODD COVERING SYSTEM (Erdős Problem #7)
   - Status: OPEN ($2,000 Cash Bounty on erdosproblems.com #7).
   - Statement: Can a covering system of arithmetic progressions have all moduli
     pairwise distinct, odd integers > 1?
   - Expected Resolution: Believed NO (no counterexample exists).
   - Practical Assessment: Because it is likely true, counterexample search will fail.
     Proving the positive statement requires heavy analytic sieves.

4. TUZA'S TRIANGLE PACKING CONJECTURE (Erdős Problem #167)
   - Status: OPEN (tau(G) <= 2 * nu(G)).
   - Expected Resolution: Believed TRUE. Counterexample search is a brick wall.

PART 3: TOP RECENT JOURNAL CONJECTURES (2019–2025)
--------------------------------------------------------------------------------

1. THE FRACTIONAL DOMATIC GAP CONJECTURE (Gadouleau, Harms, Mertzios, Zamaraev)
   - Publication: Discrete Mathematics, Vol. 347, Issue 4, April 2024 (arXiv:2302.11668).
   - Statement: If the fractional domatic number d_f(G) > 2, then d_f(G) >= 7/3 (~2.3333).
     Equivalently, no graph has fractional domination number gamma_f(G) in (3/7, 1/2)
     = (0.42857, 0.50000).
   - Proven Range: Proven for n <= 8, trees, cycles, and complete multipartite graphs.
   - Vulnerability: For n <= 8, sub-determinants of closed neighborhood matrices can
     only take small values {2, 3, 5, 7}, creating an artificial gap. At n in [12, 24],
     circulant, Cayley, and generalized Petersen graphs have richer determinants allowing
     gamma_f(G) to fall into the gap (e.g., 4/9 = 0.444 or 5/11 = 0.454).
   - Verification Engine: Exact Linear Programming (scipy.optimize.linprog / HiGHS).
   - Lean Formalization: Primal-dual rational certificates verified via `linarith`.
   - Rubric Score: 7 / 7.

2. THE 1/3-DOMINATION CONJECTURE FOR CUBIC BIPARTITE GRAPHS (Dorbec & Henning)
   - Publication: arXiv:2401.17820 [math.CO] (2024, submitted to Journal of Graph Theory).
   - Statement: Every connected cubic bipartite graph has domination number gamma(G) <= n/3.
   - Proven Range: Proved for graphs avoiding 4-cycles and 8-cycles.
   - Vulnerability: Cubic bipartite graphs with multiple 4-cycles at n = 20, 22, 24.
   - Search Space: 168,132 graphs at n = 24, exhaustively searchable via nauty `geng`.
   - Rubric Score: 6.8 / 7.

3. THE INDUCED LINEAR FOREST DEGREE-SUM CONJECTURE (Akbari et al.)
   - Publication: Discrete Mathematics, Vol. 344, Issue 10, October 2021.
   - Statement: For every graph G with delta(G) >= 2, LIF(G) >= sum(2 / (d(v) + 1)).
   - Proven Range: Proved for r-regular graphs and Delta <= 3.
   - Vulnerability: Non-regular graphs with dense clique cores and low-degree peripheries.
   - Rubric Score: 6.4 / 7.
